Изображения, видео, музыка и речь генерируются не сразу, а через задачи: создание файла может занять от нескольких секунд до нескольких минут.

<Steps>
  <Step title="Запустите задачу">
    Отправьте `POST /v1/{images|videos|music|audio}/jobs` с моделью нужного типа. В ответе сразу придут `id` задачи, `status: "pending"` и прогноз стоимости `estimated_cost`.
  </Step>
  <Step title="Проверяйте статус">
    Запрашивайте `GET /v1/{kind}/jobs/{id}` раз в 3–5 секунд, пока `status` не станет `completed` или `failed`. Если перестать проверять, задача всё равно доработает.
  </Step>
  <Step title="Скачайте файл">
    У каждого элемента в `output` есть ссылка `url` вида `…/v1/{kind}/jobs/{id}/content?index=N`. Скачивать нужно с тем же заголовком `X-API-KEY`. Поддерживаются `Range`-запросы.
  </Step>
</Steps>

| Тип | Сколько ждать | Сколько хранится |
| --- | --- | --- |
| Изображения | От нескольких секунд до пары минут, 4K — до 5 минут | 7 дней |
| Видео | От 30 секунд до нескольких минут | 7 дней |
| Музыка | Несколько минут | Скачайте сразу |
| Речь и звук | Зависит от модели | Скачайте сразу |

Точный срок хранения указан в поле `expires_at`. После него файл недоступен, и запрос вернёт `410 content_expired`. Одновременно можно запускать ограниченное число задач, при превышении придёт `429 too_many_jobs`.

## Изображения

`POST /v1/images/jobs` генерирует картинку по описанию. Если передать `input_images`, модель отредактирует исходное изображение. Одна задача — одна картинка.

| Поле | Описание |
|---|---|
| `model`, `prompt` | Обязательные. Описание обычно до 5000 символов |
| `size` | `1:1`, `16:9`, `1k`/`2k`/`4k`, `WIDTHxHEIGHT` или `auto` |
| `input_images` | Исходные изображения (https или `data:` URI), обычно до 10 |
| `output_format` | `png` (по умолчанию), `jpeg`, `webp` |
| `quality` | `standard`, `hd` |
| `mj_task_id`, `mj_index` | Действия Midjourney |

## Видео

`POST /v1/videos/jobs`. Режим зависит от того, что вы передали:

- только `prompt` — видео по описанию;
- `image_url` (и по желанию `last_frame_url`) — видео из картинки;
- `reference_image_urls` или `video_urls` — видео по референсам;
- `video_url` вместе с `image_url` — перенос движения.

| Поле | Описание |
|---|---|
| `model`, `prompt` | Обязательные. Описание до 10 000 символов |
| `duration` | Длительность в секундах. У каждой модели свои варианты: Veo — 4/6/8, Kling — 5/10, Seedance — 4–15 |
| `aspect_ratio` | `16:9` (по умолчанию), `9:16`, `1:1` и другие |
| `resolution` | `480p`, `720p`, `1080p`, `4k` |
| `audio` | Звуковая дорожка, если модель умеет. Может стоить дороже |
| `mode` | `standard`, `pro`, `master` |
| `output_format` | `mp4` (по умолчанию), `mov`, `webm` |

## Музыка

`POST /v1/music/jobs`. Если передать только `prompt`, модель сама напишет текст и подберёт стиль. Чтобы управлять результатом, используйте `lyrics` (до 5000 символов), `style` (до 1000), `title` (до 200) и `instrumental`. Некоторые модели возвращают два трека по цене одного.

## Речь и звук

`POST /v1/audio/jobs`. Какие поля нужны, зависит от задачи:

- озвучка текста — `text` и `voice`;
- диалог — `dialogue`, список реплик с `text` и `voice`;
- звуковой эффект — `text` и `duration_seconds` (до 30 секунд);
- выделение голоса из записи — `audio_url`.

Дополнительно можно передать `language_code`, `speed` (от 0,7 до 1,2), `stability` и `similarity_boost`.

## Пример

```python
import os, time, requests

BASE = "https://b2b.api.ascn.ai/api/ai-gateway"
HEADERS = {"X-API-KEY": os.environ["ASCN_API_KEY"]}

job = requests.post(f"{BASE}/v1/images/jobs", headers=HEADERS, json={
    "model": "google/nano-banana-2",
    "prompt": "A cozy cabin at sunrise, cinematic light",
    "size": "16:9",
}).json()

while job["status"] not in ("completed", "failed"):
    time.sleep(4)
    job = requests.get(f"{BASE}/v1/images/jobs/{job['id']}", headers=HEADERS).json()

print(job["output"][0]["url"] if job["status"] == "completed" else job["error"])
```

## Если задача не выполнилась

| `error.code` | Что делать |
|---|---|
| `content_moderation` | Переформулируйте описание |
| `input_rejected` | Замените исходный файл. Причина в поле `message` |
| `invalid_request` | Поправьте параметры, подсказка в `message` |
| `generation_failed`, `job_expired` | Запустите задачу заново |

За неудачные задачи деньги не списываются. Исходные файлы должны открываться по https без авторизации.
