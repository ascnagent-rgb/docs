Ошибки приходят в том же формате, что и у OpenAI, плюс два поля: `status_code` и `request_id`. Если пишете в поддержку, приложите `request_id`.

```json
{
  "error": {
    "message": "model \"x\" is not available",
    "type": "invalid_request_error",
    "code": "model_not_found"
  },
  "status_code": 404,
  "request_id": "req_…"
}
```

| HTTP | `code` | Что случилось |
| --- | --- | --- |
| 400 | `model_required` | Тело запроса не в формате JSON или в нём нет `model`. |
| 400 | `invalid_request_error` | Модель отклонила запрос. Причина в поле `message`. |
| 400 | `context_length_exceeded` | Запрос вместе с `max_tokens` не помещается в контекстное окно модели. |
| 400 | `streaming_required` | Ответ слишком длинный. Повторите запрос с `"stream": true`. |
| 400 | `unsupported_parameter`, `unsupported_value` | Модель не поддерживает этот параметр или значение. |
| 400 | `content_policy_violation` | Модель отказалась обрабатывать запрос из-за его содержания. |
| 400 | `wrong_endpoint` | Модель работает через другой метод API. Какой именно, написано в `message`. |
| 402 | `insufficient_balance` | Не хватает свободных средств. Подробности в `meta`: `required_micro_usd`, `balance_micro_usd`, `held_micro_usd`. |
| 404 | `model_not_found` | Такой модели нет в списке. |
| 404 | `not_found` | Такого метода API нет. |
| 404 | `job_not_found` | У вашего аккаунта нет задачи с таким `id`. |
| 409 | `job_not_completed` | Задача ещё не завершилась. |
| 410 | `content_expired` | Срок хранения файла истёк. |
| 413 | `request_too_large` | Слишком большое тело запроса. |
| 429 | `rate_limited` | Слишком много запросов. Повторите после паузы из заголовка `Retry-After`. |
| 429 | `too_many_jobs` | Запущено максимальное число медиа-задач. |
| 502 | `backend_error` | Сбой на стороне провайдера. Запрос можно повторить. |
| 503 | `no_provider_active` | Сервис временно недоступен. |
| 503 | `model_unavailable` | Модель сейчас не может выполнить запрос с такими параметрами. |

## Когда повторять запрос

- `429` — после паузы из заголовка `Retry-After`.
- `502` — сразу или через пару секунд.
- `503` — позже или с другой моделью.
- `400` и `404` повторять бесполезно, сначала поправьте запрос.
