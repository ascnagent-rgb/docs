ASCN Router работает по протоколу OpenAI, поэтому переписывать код не нужно. Обычно достаточно поменять три вещи: адрес API, заголовок с ключом и название модели.

## Если вы работали с OpenAI напрямую

<CodeGroup>

```python Python
import os
from openai import OpenAI

# Было:
# client = OpenAI(api_key=os.environ["OPENAI_API_KEY"])

# Стало:
key = os.environ["ASCN_API_KEY"]
client = OpenAI(
    base_url="https://b2b.api.ascn.ai/api/ai-gateway/v1",
    api_key=key,
    default_headers={"X-API-KEY": key},
)

response = client.chat.completions.create(
    model="openai/gpt-4o-mini",  # было: "gpt-4o-mini"
    messages=[{"role": "user", "content": "Hello!"}],
)
```

```javascript Node.js
import OpenAI from "openai";

// Было:
// const client = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

// Стало:
const key = process.env.ASCN_API_KEY;
const client = new OpenAI({
  baseURL: "https://b2b.api.ascn.ai/api/ai-gateway/v1",
  apiKey: key,
  defaultHeaders: { "X-API-KEY": key },
});

const response = await client.chat.completions.create({
  model: "openai/gpt-4o-mini", // было: "gpt-4o-mini"
  messages: [{ role: "user", content: "Hello!" }],
});
```

</CodeGroup>

## Если вы работали через другой шлюз

Если вы уже пользуетесь другим сервисом, где модели называются в формате `vendor/model`, поменяйте адрес и ключ так же, как в примере выше. Названия моделей сверьте со списком `GET /v1/models`: они могут не совпадать.

## Что проверить

- Адрес API: `https://b2b.api.ascn.ai/api/ai-gateway/v1`.
- Ключ передаётся в заголовке `X-API-KEY`.
- В названии модели есть провайдер, например `anthropic/claude-haiku-4.5`. Регистр и разделители не важны.
- Responses API не хранит ответы, поэтому `previous_response_id` не работает. Историю диалога передавайте целиком в `input`.
- Картинки, видео и речь генерируются через [медиа-задачи](/router/media), а не через синхронные методы OpenAI.
- Моделям с рассуждениями ставьте `max_tokens` от 2000.
