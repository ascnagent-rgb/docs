ASCN Router — единый API для моделей OpenAI, Anthropic, Google, DeepSeek, xAI, Qwen, Mistral и других провайдеров. Он совместим с OpenAI API, поэтому подойдёт любой OpenAI SDK: достаточно поменять адрес и ключ, а модель выбрать из списка `GET /v1/models`.

<Tip>
  Если пишете код вместе с ИИ-ассистентом, скопируйте [инструкцию для ИИ](/router/ai-prompt) и вставьте её в чат.
</Tip>

## Базовый URL

```text
https://b2b.api.ascn.ai/api/ai-gateway
```

Пути всех методов начинаются с `/v1`. В настройках OpenAI SDK указывайте адрес вместе с `/v1`.

## Авторизация

Ключ API передаётся в заголовке `X-API-KEY` в каждом запросе, в том числе при скачивании файлов.

```http
X-API-KEY: <ваш_ключ>
```

OpenAI SDK сам кладёт ключ в заголовок `Authorization`, поэтому `X-API-KEY` нужно добавить вручную через дополнительные заголовки. Как это сделать, показано в примерах ниже.

<Warning>
Держите ключ на сервере, например в переменной окружения. Не вставляйте его в клиентский код и не коммитьте в репозиторий.
</Warning>

## Первый запрос

<CodeGroup>

```bash cURL
curl https://b2b.api.ascn.ai/api/ai-gateway/v1/chat/completions \
  -H "X-API-KEY: $ASCN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek/deepseek-v4-flash",
    "messages": [{"role": "user", "content": "What is 1+1? Answer with a single number."}]
  }'
```

```python Python
import os
from openai import OpenAI

key = os.environ["ASCN_API_KEY"]
client = OpenAI(
    base_url="https://b2b.api.ascn.ai/api/ai-gateway/v1",
    api_key=key,
    default_headers={"X-API-KEY": key},
)

response = client.chat.completions.create(
    model="deepseek/deepseek-v4-flash",
    messages=[{"role": "user", "content": "What is 1+1? Answer with a single number."}],
)
print(response.choices[0].message.content)
```

```javascript Node.js
import OpenAI from "openai";

const key = process.env.ASCN_API_KEY;
const client = new OpenAI({
  baseURL: "https://b2b.api.ascn.ai/api/ai-gateway/v1",
  apiKey: key,
  defaultHeaders: { "X-API-KEY": key },
});

const response = await client.chat.completions.create({
  model: "deepseek/deepseek-v4-flash",
  messages: [{ role: "user", content: "What is 1+1? Answer with a single number." }],
});
console.log(response.choices[0].message.content);
```

</CodeGroup>

## Методы API

| Метод | Путь | Что делает |
| --- | --- | --- |
| `POST` | `/v1/chat/completions` | Генерация текста (Chat Completions) |
| `POST` | `/v1/responses` | Генерация текста (Responses) |
| `GET` | `/v1/models`, `/v1/models/{model}` | Список моделей и цены |
| `POST` | `/v1/{images\|videos\|music\|audio}/jobs` | Запуск медиа-задачи |
| `GET` | `/v1/{kind}/jobs/{id}` | Статус задачи |
| `GET` | `/v1/{kind}/jobs/{id}/content` | Скачать результат |

В каждом ответе есть заголовок `X-Request-ID`. Если пишете в поддержку, приложите его.
