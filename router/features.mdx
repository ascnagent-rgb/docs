Все поля Chat Completions передаются модели как есть. Поддерживает ли модель ту или иную возможность, зависит от неё самой, поэтому сначала проверьте модель в `GET /v1/models`.

## Картинки на входе

Если у модели в `input_modalities` есть `image`, ей можно отправлять картинки. Для этого передайте `content` массивом:

```python
response = client.chat.completions.create(
    model="openai/gpt-4o-mini",
    messages=[{
        "role": "user",
        "content": [
            {"type": "text", "text": "Что на этой картинке?"},
            {"type": "image_url", "image_url": {"url": "https://example.com/photo.jpg"}},
        ],
    }],
)
```

## Ответ в формате JSON

Поле `response_format` уходит модели без изменений. Если модель его поддерживает, она вернёт JSON по вашей схеме:

```python
response = client.chat.completions.create(
    model="openai/gpt-4o-mini",
    messages=[{"role": "user", "content": "Назови столицу Франции и её население."}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "city",
            "schema": {
                "type": "object",
                "properties": {
                    "city": {"type": "string"},
                    "population": {"type": "integer"},
                },
                "required": ["city", "population"],
            },
        },
    },
)
```

<Tip>
Если модель не поддерживает `response_format`, API может вернуть ошибку `400 unsupported_parameter`, а может и просто проигнорировать поле. В таком случае опишите нужный формат прямо в промпте.
</Tip>

## Вызов функций

<Steps>
  <Step title="Опишите функции">
    Передайте их в `tools`. Если модель решит вызвать функцию, в ответе будет `finish_reason: "tool_calls"`.
  </Step>
  <Step title="Выполните функцию у себя">
    Название и аргументы лежат в `message.tool_calls`.
  </Step>
  <Step title="Верните результат модели">
    Добавьте в историю ответ модели и сообщение с `role: "tool"` и тем же `tool_call_id`. Потом отправьте запрос ещё раз.
  </Step>
</Steps>

```python
import json

tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "Current weather for a city.",
        "parameters": {"type": "object", "properties": {"city": {"type": "string"}}, "required": ["city"]},
    },
}]
messages = [{"role": "user", "content": "Какая погода в Берлине?"}]

first = client.chat.completions.create(model="openai/gpt-4o-mini", messages=messages, tools=tools)
call = first.choices[0].message.tool_calls[0]
args = json.loads(call.function.arguments)

result = {"city": args["city"], "temp_c": 18}  # здесь ваша функция

messages.append(first.choices[0].message)
messages.append({"role": "tool", "tool_call_id": call.id, "content": json.dumps(result)})

final = client.chat.completions.create(model="openai/gpt-4o-mini", messages=messages, tools=tools)
print(final.choices[0].message.content)
```

## Кэширование промпта

Некоторые модели кэшируют повторяющийся промпт. Сколько токенов взято из кэша, видно в `usage.prompt_tokens_details.cached_tokens`. Если у модели в списке указана цена `cached_input_per_mtok`, такие токены оплачиваются по ней, если нет — по обычной цене входа.

Чтобы кэш срабатывал чаще, ставьте то, что не меняется (системный промпт, инструкции, документы), в начало сообщений, а то, что меняется, — в конец.
