Для текста есть два метода, оба повторяют API OpenAI. Подходят модели с `kind: text` из `GET /v1/models`.

## Chat Completions

```http
POST /v1/chat/completions
```

Все поля запроса передаются модели без изменений: `tools`, `tool_choice`, `response_format`, `logprobs`, `seed`, `stop` и остальные. Поддерживает ли модель конкретное поле, зависит от самой модели.

<ParamField body="model" type="string" required>
  Название модели, например `deepseek/deepseek-v4-flash`.
</ParamField>
<ParamField body="messages" type="object[]" required>
  История диалога. `role`: `system`, `developer`, `user`, `assistant` или `tool`. `content`: текст или массив частей (`text`, `image_url` и т. д.).
</ParamField>
<ParamField body="max_tokens" type="integer">
  Максимум токенов в ответе, включая рассуждения.
</ParamField>

<ParamField body="stream" default="false" type="boolean">
</ParamField>

<ParamField body="temperature" type="number">
  От 0 до 2.
</ParamField>
<ParamField body="reasoning_effort" type="string">
  `minimal`, `low`, `medium` или `high`.
</ParamField>

<ParamField body="tools" type="object[]">
</ParamField>

<ParamField body="tool_choice" type="string | object">
  `none`, `auto`, `required` или конкретная функция.
</ParamField>

Ответ приходит в стандартном формате `chat.completion`: массив `choices` с полями `message` и `finish_reason` (`stop`, `length`, `tool_calls`, `content_filter`) и объект `usage`. В `completion_tokens` входят и скрытые рассуждения.

```bash Вызов функции
curl https://b2b.api.ascn.ai/api/ai-gateway/v1/chat/completions \
  -H "X-API-KEY: $ASCN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-4o-mini",
    "messages": [{"role": "user", "content": "What is the weather in Berlin?"}],
    "tools": [{
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Current weather for a city.",
        "parameters": {"type": "object", "properties": {"city": {"type": "string"}}, "required": ["city"]}
      }
    }]
  }'
```

## Responses

```http
POST /v1/responses
```

Подойдёт, если ваш код уже написан под `client.responses.create`. Обязательные поля: `model` и `input` (строка или массив сообщений). Также можно передать `instructions`, `max_output_tokens`, `temperature`, `tools` и `stream`.

<Warning>
Ответы не сохраняются на сервере, поэтому `previous_response_id` и получение ответа позже не работают. Передавайте всю историю в `input`.
</Warning>

```python
response = client.responses.create(
    model="openai/gpt-4o-mini",
    input="Summarise the CAP theorem in three bullets.",
    max_output_tokens=400,
)
print(response.output_text)
```

## Стриминг

Чтобы получать ответ по частям через Server-Sent Events, передайте `"stream": true`. Поток заканчивается строкой `data: [DONE]`.

- В Chat Completions всегда включён `stream_options.include_usage`, а в последнем чанке приходит `usage`.
- В Responses приходят события `response.output_text.delta` и другие. `usage` будет в последнем событии `response.completed`.

<Tip>
Длинные ответы запрашивайте со стримингом. Без него запрос может вернуть ошибку `streaming_required`.
</Tip>

```python
stream = client.chat.completions.create(
    model="anthropic/claude-haiku-4.5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain mixture-of-experts in one paragraph."}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
```

Если провайдер упадёт посреди ответа, переключиться на другого уже не получится. Поток закончится чанком `data: {"error": {…}}` и строкой `data: [DONE]`. То, что успело прийти, считайте неполным ответом.
