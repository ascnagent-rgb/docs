## What is ASCN Agent?

A personal AI assistant connected to your services (Gmail, Calendar, Slack, etc.) that can work on its own — on a schedule or on triggers — and talk to you via web, Telegram or Slack.

## Is it safe?

Your data is stored in an isolated workspace, integration tokens are encrypted, and you can revoke access at any time. The agent doesn't use your data to train external models.

## How much does it cost?

There's a free plan to try things out. Paid plans add more credits and channels. See pricing on [ascn.ai](https://ascn.ai).

## Can the agent send emails on my behalf?

Yes, if you allow it. By default, the agent prepares drafts and asks for confirmation before sending. You can change this behaviour in IDENTITY.md.

## Can it access services that aren't in the integrations list?

Yes — via API or MCP (Model Context Protocol). See [Integrations](/en/brain/connectors).

## What's the difference between Memory and Knowledge?

Knowledge is what you fill in manually (role, preferences, documents). Memory is what the agent automatically learns from chat. Knowledge has priority in case of conflicts.

## How do I delete an agent?

**Settings → Danger zone → Delete workspace**. All data is permanently erased.
