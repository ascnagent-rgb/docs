Cada ASCN Agent é feito de três camadas.

![Estrutura](/images/05-architecture-sidebar.png)

## Cérebro — centro de controle

- **Integrações** — a quais serviços o agente acessa
- **Habilidades** — padrões de comportamento reutilizáveis
- **Conhecimento** — quem o agente é
- **Memória** — o que ele lembra sobre você

## Tarefas — automações

| Tipo | Exemplo |
| --- | --- |
| **Agendada** | Toda manhã às 8h — resumo de e-mails |
| **Gatilho** | Novo e-mail → prepara rascunho |

## Canais

- **Chat ASCN** — interface web
- **Telegram** — bot via BotFather
- **Slack** — workspace da equipe
