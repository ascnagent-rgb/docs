---
title: "Memória"
description: "Como o agente lembra informações entre sessões."
---

**Memória** é o que o agente aprende automaticamente.

## Controle

```text
Lembre-se: prefiro respostas curtas.
```

```text
Esqueça o que falei sobre o projeto X.
```

## Memória vs Conhecimento

| Memória | Conhecimento |
| --- | --- |
| Automática | Manual |
| Detalhes pessoais | Regras, referência |

Conhecimento tem prioridade em caso de conflito.
