---
title: "Ereignis-Trigger"
description: "Der Agent reagiert auf Ereignisse in Ihren Diensten."
---

Ein **Trigger** ist eine Bedingung, bei deren Eintreten der Agent eine Aktion automatisch ausführt.

## Verfügbare Trigger

| Dienst | Ereignis |
| --- | --- |
| **Gmail** | Neue E-Mail |
| **Google Kalender** | Event erstellt/geändert/gelöscht |
| **Google Drive** | Datei hinzugefügt/geändert |

## Trigger erstellen

```text
Wenn eine neue E-Mail in Gmail ankommt, prüfe, ob eine Antwort nötig ist,
und bereite einen Entwurf zur Bestätigung in Telegram vor.
```

<Warning>
  Trigger verbrauchen Integrations-Credits bei jeder Aktivierung.
</Warning>
