---
title: "Geplante Aufgaben"
description: "Lassen Sie den Agenten Aufgaben automatisch zur richtigen Zeit ausführen."
---

Eine **geplante Aufgabe** ist ein Szenario, das der Agent zur richtigen Zeit selbst ausführt.

## Aufgabe erstellen

```text
Jeden Morgen um 8:00 Uhr eine Übersicht ungelesener E-Mails in Gmail erstellen 
und mir in Telegram senden.
```

## Planungsformate

| Format | Beispiel |
| --- | --- |
| Alle N Minuten | Alle 30 Minuten |
| Täglich | Jeden Tag um 09:00 |
| Wochentage | Jeden Montag |
