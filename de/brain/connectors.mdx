Eine Integration ist die Verbindung zwischen dem Agenten und einem Dienst, den Sie nutzen.

## Standard verfügbar

- **Web-Suche** — findet aktuelle Informationen
- **Seitenleser** — liest jede öffentliche URL

## Was Sie verbinden können

| Dienst | Was der Agent macht |
| --- | --- |
| **Gmail** | Liest, entwirft, sendet, sortiert |
| **Google Kalender** | Sieht Meetings, erstellt Events |
| **Google Drive** | Öffnet Dateien, beobachtet Änderungen |
| **Slack** | Liest Kanäle und schreibt Nachrichten |
| **GitHub / GitLab** | Issues, Branches, PRs |

## Manuelle Verbindung

1. **Gehirn → Integrationen** öffnen
2. Dienst finden
3. **\+ Hinzufügen** klicken
