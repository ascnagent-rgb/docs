---
title: "Gedächtnis"
description: "Wie der Agent zwischen Sitzungen Informationen speichert."
---

**Gedächtnis** ist das, was der Agent während der Arbeit über Sie lernt. Im Gegensatz zum Wissen, das Sie manuell füllen, bildet sich Gedächtnis automatisch.

## Steuerung

```text
Merke dir: ich bevorzuge kurze Antworten ohne Einleitungen.
```

```text
Vergiss, was ich über Projekt X gesagt habe.
```

## Gedächtnis vs Wissen

| Gedächtnis | Wissen |
| --- | --- |
| Automatisch | Manuell |
| Persönliche Details | Rollen, Regeln |
| Ändert sich | Bleibt stabil |

Bei Konflikten hat Wissen Priorität.
