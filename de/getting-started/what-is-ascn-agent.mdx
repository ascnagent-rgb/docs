---
title: "Was ist ASCN Agent?"
description: "Ein KI-Assistent, der für Sie arbeitet — während Sie mit anderem beschäftigt sind."
---

ASCN Agent ist Ihr persönlicher KI-Assistent. Sie erklären ihm, was er tun soll und auf welche Dienste er zugreifen darf. Danach arbeitet er selbständig: liest E-Mails, beobachtet den Kalender, sendet das Wichtige an Telegram oder Slack — ohne Ihre Beteiligung.

## Woraus er besteht

1. **Gehirn** — wer der Agent ist, womit er verbunden ist, welche Dokumente er kennt
2. **Aufgaben** — was der Agent von sich aus tut und wann
3. **Kanäle** — wo der Agent mit Ihnen spricht: ASCN, Telegram, Slack
