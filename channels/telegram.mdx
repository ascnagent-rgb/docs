Telegram — самый удобный способ взаимодействовать с агентом вне браузера: получать уведомления, задавать вопросы и давать команды прямо из мессенджера.

## Как подключить Telegram

### Шаг 1. Создайте бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Напишите команду `/newbot`
3. Задайте имя бота (отображаемое) и username (должен заканчиваться на `_bot`)
4. BotFather выдаст вам **токен** — скопируйте его

[КАРТИНКА. Диалог с BotFather — шаги создания бота и получения токена]

### Шаг 2. Подключите бота в ASCN

1. Откройте раздел **Каналы** в настройках агента
2. Выберите **Telegram**
3. Вставьте токен в поле **Bot Token**
4. Нажмите **Подключить бота**

[КАРТИНКА. Раздел Каналы → Telegram — поле ввода токена и кнопка «Подключить бота»]

### Шаг 3. Начните разговор

Найдите своего бота в Telegram по username и напишите `/start`. Агент готов к работе.

## Что можно делать через Telegram

После подключения агент работает в Telegram как полноценный ассистент:

- Задавать вопросы и получать ответы
- Давать команды: «отправь письмо», «забронируй встречу», «что у меня сегодня?»
- Получать уведомления от триггеров и задач по расписанию
- Загружать файлы и изображения прямо в чат

**Пример команд:**

```
Что у меня в почте за сегодня?
```

```
Отправь письмо Ивану Петрову: подтверждаю встречу на пятницу в 15:00.
```

```
Запишись на встречу с командой завтра в 11:00, название "Синк по продукту".
```

## Ограничение доступа к боту

По умолчанию бот доступен только вам. Если хотите ограничить доступ явно — настройте это в **Настройках агента → Telegram → Доступ**.

<Tip>
Удобный паттерн: подключите Telegram-уведомления для срочных событий (важные письма, изменения встреч), а утреннюю сводку — через задачу по расписанию прямо в чат.
</Tip>
