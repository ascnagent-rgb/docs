**Коннекторы** — это подключения к внешним сервисам. После подключения агент может читать данные из этих сервисов и выполнять в них действия.

## Доступные коннекторы

| Коннектор | Что умеет агент |
|-----------|----------------|
| **Gmail** | Читать письма, создавать черновики, отправлять письма, сортировать по папкам |
| **Google Calendar** | Читать события, создавать встречи, обновлять и удалять события |
| **Google Drive** | Читать файлы, создавать документы, отслеживать изменения |
| **Slack** | Читать сообщения, отправлять сообщения в каналы и в личку |
| **GitHub** | Читать репозитории, issues, pull requests; создавать issues |

## Как подключить коннектор

[КАРТИНКА. Экран Brain → Интеграции → Коннекторы с кнопками «Подключить»]

1. Откройте **Brain → Интеграции**
2. Перейдите на вкладку **Коннекторы**
3. Найдите нужный сервис и нажмите **Подключить**
4. Подтвердите запрошенные разрешения в открывшемся окне

<Info>
После подключения агент автоматически предложит действия и сценарии на основе нового коннектора.
</Info>

## Управление подключённым коннектором

После подключения коннектор появляется во вкладке **Подключённые**. Нажмите иконку **···** на карточке, чтобы управлять правами.

### Режимы доступа

| Режим | Описание |
|-------|----------|
| **Только чтение** | Агент видит данные, но не может ничего изменять |
| **Полный доступ** | Агент может создавать, редактировать и удалять данные |

### Другие действия

- **Сменить аккаунт** — привязать другую учётную запись
- **Отключить** — временно приостановить работу коннектора
- **Удалить** — полностью убрать коннектор

<Warning>
При удалении коннектора все задачи и триггеры, которые его используют, перестанут работать.
</Warning>

## Настройка правил для коннектора

В разделе [Права инструментов](/settings/permissions) можно задать конкретные ограничения для каждого коннектора.

**Пример для Gmail:**
```
Только читать и резюмировать письма, никогда не отправлять 
и не удалять без явного подтверждения пользователя.
```

Это позволяет дать агенту доступ к почте, но ограничить риски нежелательных действий.
