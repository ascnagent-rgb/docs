**Права инструментов** позволяют задать точные ограничения для каждого коннектора: что агент может делать самостоятельно, а что — только с вашего явного разрешения.

[КАРТИНКА. Раздел Настройки → Права инструментов — список коннекторов с правилами]

## Зачем нужны права инструментов

По умолчанию агент действует в рамках выданных при подключении разрешений (только чтение или полный доступ). Права инструментов дают более тонкую настройку.

**Пример ситуации:** вы дали Gmail полный доступ, чтобы агент мог отправлять письма. Но хотите, чтобы перед каждой отправкой он спрашивал подтверждения — на случай ошибки.

## Как добавить правило

В разделе **Настройки → Права инструментов** выберите коннектор и опишите правило в свободной форме:

**Gmail:**
```
Только читать и резюмировать письма. 
Перед отправкой любого письма — обязательно показать черновик и спросить подтверждения.
Никогда не удалять письма без явного указания.
```

**Google Calendar:**
```
Читать события без ограничений.
При создании или изменении встречи — сначала показать детали и спросить подтверждения.
```

**Google Drive:**
```
Читать файлы можно свободно.
Создание и изменение файлов — только после подтверждения.
Удаление файлов запрещено.
```

## Рекомендации

<Tip>
Начните с режима «только чтение» для всех коннекторов. Разрешайте действия постепенно, по мере того как убедитесь в корректности поведения агента.
</Tip>

- Для почты и календаря рекомендуем требовать подтверждение перед любым действием, которое меняет данные
- Для задач по расписанию (например, утренней сводки) подтверждение не нужно — агент только читает
- Правила пишутся на русском языке в свободной форме — агент их понимает
