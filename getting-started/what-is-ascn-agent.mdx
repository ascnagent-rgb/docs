ASCN Agent — это постоянный ИИ-ассистент, которого вы настраиваете один раз, а он работает самостоятельно: мониторит почту, готовит отчёты, напоминает о встречах, отвечает на сообщения в Telegram и выполняет рутинные задачи по расписанию.

[КАРТИНКА. Главный экран ASCN Agent — интерфейс с агентом в чате]

## Чем агент отличается от обычного чат-бота

Обычный чат-бот отвечает на вопросы. ASCN Agent **действует**:

- **Подключается к вашим инструментам** — Gmail, Google Calendar, Google Drive, Slack, GitHub
- **Работает в фоне** — выполняет задачи по расписанию без вашего участия
- **Реагирует на события** — пришло письмо, создана встреча, появился файл
- **Помнит контекст** — между сессиями, между днями
- **Общается там, где удобно вам** — в интерфейсе ASCN, Telegram или Slack

## Типичные сценарии

**Почта и встречи.** Агент читает входящие, сортирует письма, готовит черновики ответов. Каждое утро присылает сводку важного. Напоминает о встречах из Google Calendar.

**Управление через Telegram.** Скажите агенту в Telegram «отправь письмо Ивану» или «забронируй встречу на пятницу» — он сделает это за вас.

**Ежедневные отчёты.** По расписанию агент собирает данные из нужных источников и присылает структурированную сводку.

## Как это работает

Агент состоит из трёх частей:

1. **Brain (Мозг)** — здесь вы задаёте, к чему агент подключён, как он себя ведёт и что знает о вас
2. **Tasks (Задачи)** — автоматизации по расписанию и по событиям
3. **Channels (Каналы)** — где агент общается с вами: ASCN, Telegram, Slack
