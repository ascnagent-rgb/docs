## Шаг 1. Войдите в ASCN

Откройте [ascn.ai](https://ascn.ai/ru/agent) и войдите в свой аккаунт.

## Шаг 2. Перейдите в раздел «Агенты»

В боковом меню выберите **Агенты**.

[КАРТИНКА. Боковое меню ASCN — раздел «Агенты» выделен]

## Шаг 3. Создайте нового агента

Нажмите **Создать нового Агента**.

[КАРТИНКА. Кнопка «Создать нового Агента» на странице Агенты]

## Шаг 4. Опишите задачу

В поле чата напишите, чем должен заниматься агент. Чем конкретнее — тем лучше.

**Примеры:**

```
Следи за дедлайнами в моём Google Календаре. За день до дедлайна 
напоминай мне о задаче и спрашивай, нужна ли помощь с подготовкой.
```

```
Каждое утро в 9:00 присылай мне сводку непрочитанных писем в Gmail 
с кратким описанием каждого.
```

```
Когда приходит новое письмо, проверь, нужен ли ответ, и подготовь черновик.
```

<Tip>
Начните с задачи, которую вы уже делаете регулярно вручную. Делегировать привычное — самый быстрый способ увидеть ценность агента.
</Tip>

## Шаг 5. Подключите нужные инструменты

Агент сам предложит подключить коннекторы, которые нужны для задачи. Например, для мониторинга почты — Gmail.

Чтобы подключить самостоятельно: **Мозг → Интеграции → Коннекторы** → найдите нужный и нажмите **Подключить**.

[КАРТИНКА. Экран подключения коннектора — кнопка «Подключить» рядом с Gmail]

## Шаг 6. Запустите агента

После описания задачи и подключения инструментов — агент готов к работе. Общайтесь с ним прямо в чате ASCN или подключите [Telegram](/channels/telegram).
