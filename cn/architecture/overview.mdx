title: "Agent 的工作原理"
description: "ASCN Agent 的三层架构：大脑、任务、渠道。"
---

每个 ASCN Agent 由三层组成。

![结构](/images/05-architecture-sidebar.png)

## 大脑 —— 控制中心

- **集成** —— 可访问的服务
- **技能** —— 可重复的行为模式
- **知识** —— Agent 是谁
- **记忆** —— 关于你的记忆

## 任务 —— 自动化

| 类型 | 示例 |
| --- | --- |
| **定时** | 每天早上 8 点 —— 邮件摘要 |
| **触发** | 新邮件 → 准备草稿 |

## 渠道

- **ASCN 聊天** —— Web 界面
- **Telegram** —— 通过 BotFather
- **Slack** —— 团队工作区
