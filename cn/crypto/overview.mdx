
| 状态码 | 含义 | 描述 |
| --- | --- | --- |
| `200` | OK | 请求成功。 |
| `400` | Bad Request | 请求格式错误或缺少必要参数。 |
| `401` | Unauthorized | API key 不正确或缺失。 |
| `403` | Forbidden | API key 无权执行此操作。 |
| `429` | Too Many Requests | 超出速率限制。 |

## 📚 API 参考

### POST /invoke_assistant

向 AI 助手发送消息，返回完整的结构化分析。

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `message` | string | **必填。** 自然语言问题或消息。 |
| `chat_id` | uuid | 可选。继续现有对话的聊天 ID。 |
| `model` | string | 可选。AI 模型，默认值：`ascn_v1.2`。 |

```json
{
  "message": "对 BONK 进行深度链上和市场分析",
  "model": "ascn_v1.2"
}
```

### POST /invoke_assistant_stream

实时应用程序的 SSE 流——在响应生成时逐步传递内容，适合交互式实时体验。
