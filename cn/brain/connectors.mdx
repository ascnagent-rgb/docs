## 默认可用

- **网络搜索**
- **页面阅读器**

## 可连接的服务

| 服务 | Agent 能做什么 |
| --- | --- |
| **Gmail** | 阅读、起草、发送、排序 |
| **Google 日历** | 查看会议、创建事件 |
| **Google Drive** | 打开和创建文件 |
| **Slack** | 阅读频道、发送消息 |
| **GitHub / GitLab** | Issues、Branch、PR |

## 手动连接

1. **大脑 → 集成**
2. 找到服务
3. 点击 **\+ 添加**
