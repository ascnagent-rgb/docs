---
title: "文件和结果"
description: "你上传的文件和 Agent 创建的结果存放在哪里。"
---

每个 Agent 都有一个**工作区**：一个隔离的文件环境。这里存放 Agent 可以引用的文档、文件夹和其他资源，既包括你上传的，也包括它在工作中创建的。

## 如何添加文件？

打开**文件**，然后：

- 上传单个文件或整个文件夹
- 创建文件夹来整理工作区

也可以直接在聊天中附加文件，它们会保存到工作区。

## Agent 能对文件做什么？

- 阅读文档并回答关于内容的问题
- 从 PDF、表格和其他格式中提取数据
- 创建和编辑文件：报告、日志、笔记
- 连接[集成](/cn/brain/connectors)后读取 Google 云端硬盘中的文档

例如，定时任务可以每周五把本周总结保存到文件：

```text
每周五 17:00 问我本周完成了什么，
并把回答写入 weekly_report_[日期].md。
```

## 技能和知识存放在哪里？

Agent 自己的文件也在工作区中：

| 内容 | 位置 |
| --- | --- |
| 技能 | **文件**中的 `.agents/skills/` |
| 知识核心 | **大脑 → 知识**中的 IDENTITY.md、SOUL.md、USER.md |
| 参考文档 | **大脑 → 知识 → 文档** |

这些都是普通文本文件，可以直接打开和编辑。

## Agent 可以修改或删除文件吗？

只有在你允许时才可以。修改和删除文件是**设置 → 工具权限**中的两个独立开关。详见[权限和隐私](/cn/settings/permissions)。

<Warning>
  删除工作区会永久删除 Agent 创建的所有文件。请提前保存需要的内容。
</Warning>
