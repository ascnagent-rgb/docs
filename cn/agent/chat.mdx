与 Agent 合作就是一场对话。你描述想要的结果，Agent 提出澄清问题，你再修正回答、补充背景。

## 如何给 Agent 布置任务？

在聊天中写下你想得到什么。越具体越好：说明数据来源、结果格式以及何时交付。

```text
每天早上 9:00 给我发送 Gmail 未读邮件摘要，
并简要说明每封邮件。
```

如果任务需要某个服务，Agent 会建议连接它，聊天中会出现登录按钮。

<Tip>
  从你经常做的真实任务开始：寻找潜在客户、跟踪竞争对手、准备报告、监控邮件或汇总多个工具的更新。
</Tip>

## 可以附加文件、图片和语音吗？

可以。在输入框中你可以：

- **上传文件**：文档、表格或 PDF
- **粘贴图片**：截图、照片或图表
- **语音口述**：更快地说明任务

上传的文件会保存到 Agent 的工作区。详见[文件和结果](/cn/agent/files)。

## 输入框中的建议是什么？

你们合作得越久，ASCN 的建议就越准确：它会根据当前对话推荐现成的提示词、所需的连接器和工作流。建议直接出现在输入框中，会适配你的语言，并在你需要新的起点时更新。

## 如何让 Agent 按我的方式工作？

有三种互补的方式：

- **在聊天中告诉它**：「记住：我喜欢列表形式的回答」。Agent 会保存到[记忆](/cn/brain/memory)中。
- **在知识中写规则**：在 IDENTITY.md、SOUL.md 和 USER.md 中写下角色、风格和限制。详见[知识](/cn/brain/knowledge)。
- **创建技能**：为典型任务创建可重复的行为。详见[技能](/cn/brain/skills)。

## 还能在哪里给 Agent 发消息？

除了 ASCN 网页聊天，还可以在 [Telegram](/cn/channels/telegram) 和 [Slack](/cn/channels/slack) 中给 Agent 发消息。定时任务和触发器的通知也会发到那里。

如需与自有系统集成，请使用 [API](/cn/settings/api)：每次对话都是一个有独立 `session_id` 的会话。
