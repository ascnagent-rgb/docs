## 快速诊断

| 你看到的情况 | 处理方法 |
| --- | --- |
| Agent 卡住、无响应或行为异常 | 在**设置 → 危险区域 → 重启**中重启 |
| 修改集成后任务停止工作 | 检查**大脑 → 集成**中服务是否已连接 |
| 定时任务没有运行 | 打开**任务**，检查状态：**活动**或**暂停** |
| 机器人在 Telegram 群组中不回复 | 用 @username 提及机器人，或回复它的消息 |
| Agent 无法在 Telegram 频道发帖 | 将机器人设为有发布权限的管理员，并检查 Chat ID |
| Agent 无法在 Slack 频道发消息 | 在大脑中连接 **Slack 集成**，仅连接 Slack 渠道是不够的 |
| 额度消耗太快 | 用定时任务替代频繁的触发器，或拉长检查间隔 |
| Agent 忽略了你在聊天中说的话 | 检查知识文件，它们优先于记忆 |
| Agent 无法修改或删除文件 | 在**设置 → 工具权限**中开启相应权限 |
| 需要的服务不在集成列表中 | 在**其他连接**中通过 MCP 连接 |
| 保存后看不到密钥的值 | 这是设计使然：密钥不会显示。如需修改，请删除后重新添加 |

## Agent 没有响应，怎么办？

1. 打开**设置 → 危险区域**
2. 点击**重启**

活动会话会中断，但数据、设置和任务都会保留。无需删除工作区。

## 为什么删除集成后任务失效了？

删除连接后，所有使用该连接的任务都会停止工作。请重新连接服务。下次请先**停用**集成，确认没有影响后再删除。详见[应用和集成](/cn/brain/connectors)。

## 为什么机器人在 Telegram 群组里不说话？

在群组中，Agent 只回复用 @username 提及机器人的消息或对其消息的回复，以免刷屏。还请检查机器人是否为有发消息权限的管理员，以及**渠道 → Telegram** 中的 Chat ID 是否正确。详见 [Telegram](/cn/channels/telegram)。

## 为什么额度消耗得这么快？

每次执行任务都会消耗消息额度，调用外部服务还会消耗集成额度。如果邮件很多，为每封新邮件设置的触发器会比定时任务消耗得快得多。

- 不需要即时反应时，使用[定时任务](/cn/tasks/scheduled)
- 降低检查频率：每小时一次，而不是每 15 分钟
- [触发器](/cn/tasks/triggers)只用于紧急事项，例如 VIP 客户的邮件

## 为什么 Agent 不按我在聊天中说的做？

知识优先于记忆。如果 SOUL.md 中写着「未经明确确认不要创建会议」，即使你要求立即创建，Agent 也会先提供会议详情让你确认。要更改行为，请编辑[知识](/cn/brain/knowledge)。

## 都没用的话找谁？

联系 [Telegram 支持](https://t.me/ascnai_nocode)。说明你做了什么、期望什么、实际得到了什么，并附上截图。
