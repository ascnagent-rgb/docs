## 原则

- **每个 Agent 独立运行**：一个 Agent 的数据对其他 Agent 不可见
- **密码和密钥加密存储**：只有你能访问
- **由你决定 Agent 能做什么**：发送邮件、删除文件、创建事件，每个操作都需要你的许可
- **可随时撤销访问**：断开任何服务，或彻底删除 Agent

## 未经你许可 Agent 不会做的事

- 不会发送邮件
- 不会与其他用户共享你的数据
- 不会用你的数据训练 AI 模型
