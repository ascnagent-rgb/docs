ASCN Agent 是一个拥有独立工作区的主动式 AI Agent。用日常语言描述任务，Agent 会连接所需的服务、完成工作，并把结果发送到聊天、Telegram 或 Slack。根据你交给它的任务，它可以是你的私人助理、客服专员、营销人员或分析师。

## 为你工作的 Agent

创建一个或多个 Agent，每个角色一个。Agent 在你的应用中工作：阅读邮件、管理日历、关注文件、发布消息。在聊天中与它们交流，附加文件和图片，或用语音口述任务。

Agent 可连接 Gmail、Google 日历、Google 云端硬盘、Slack、GitHub、Notion、HubSpot 等 3000 多项服务，还能通过 MCP 或 [API](/cn/settings/api) 连接你自己的工具。
