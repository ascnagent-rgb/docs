**Интеграции** — это подключения к внешним сервисам. После подключения агент может читать данные из них и выполнять в них действия.

## Встроенные возможности

Часть функций доступна агенту по умолчанию — без дополнительных подключений:

| Возможность | Описание |
| --- | --- |
| Поиск в интернете | Агент ищет актуальную информацию в сети |
| Чтение веб-страниц | Агент может прочитать содержимое любой публичной страницы по ссылке |

## Что можно подключить

Раздел **Мозг → Интеграции** делится на три блока:

**ASCN Platform** — встроенные возможности, работают автоматически без настройки:

- Хранилище данных, файлы, автоматизации по расписанию — доступны всегда

**Приложения** — внешние сервисы, подключаются через OAuth:

| Приложение | Что умеет агент |
| --- | --- |
| **Gmail** | Читать письма, создавать черновики, отправлять, сортировать по папкам |
| **Google Calendar** | Читать события, создавать и обновлять встречи |
| **Google Drive** | Читать и создавать файлы, отслеживать изменения |
| **Google Docs / Sheets / Slides** | Читать и редактировать документы |
| **GitHub / GitLab** | Читать репозитории, issues, pull requests |
| **Slack** | Читать и отправлять сообщения в каналы |
| **Supabase / Notion** | Работа с базами данных и страницами |

**MCP Servers** — для разработчиков: подключение любых внешних инструментов через [MCP-протокол](https://modelcontextprotocol.io) (открытый стандарт для интеграции AI-инструментов).

## Как подключить приложение

![Раздел Мозг → Интеграции → Приложения с кнопками «\+ Добавить» и секцией MCP Servers](/images/07-integrations-apps.png)

1. Откройте **Мозг → Интеграции**
2. Найдите нужный сервис в разделе **Приложения**
3. Нажмите **\+ Добавить**
4. Подтвердите запрошенные разрешения

<Info>
  После подключения агент автоматически предложит действия и сценарии на основе новой интеграции.
</Info>

## Как подключить MCP-сервер

1. В разделе **MCP Servers** нажмите **\+ Добавить**
2. Укажите URL или конфигурацию сервера
3. Агент получит доступ к инструментам этого сервера

## Управление подключёнными сервисами

После подключения через карточку приложения можно:

- **Сменить аккаунт** — привязать другую учётную запись
- **Отключить** — временно приостановить
- **Удалить** — полностью убрать интеграцию

<Warning>
  При удалении интеграции все задачи и триггеры, которые её используют, перестанут работать.
</Warning>
