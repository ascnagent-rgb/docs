**ASCN Agent** — это ИИ-сотрудник, который работает за вас в фоне: следит за событиями в ваших сервисах, выполняет задачи по расписанию и общается с вами там, где удобно — в чате, Telegram или Slack.

## Чем агент отличается от чат-бота

| Чат-бот | ASCN Agent |
| --- | --- |
| Отвечает на вопросы | **Действует** и выполняет задачи |
| Работает только по запросу | Работает в фоне по расписанию и триггерам |
| Изолирован от ваших данных | Подключён к Gmail, Calendar, Drive, Slack, GitHub |
| Забывает контекст | Помнит вас и ваш стиль между сессиями |
| Один интерфейс | Доступен в ASCN, Telegram и Slack |
