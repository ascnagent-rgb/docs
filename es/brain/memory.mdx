---
title: "Memoria"
description: "Cómo recuerda el agente información entre sesiones."
---

**Memoria** es lo que el agente aprende sobre ti durante el trabajo y almacena entre sesiones. A diferencia del Conocimiento, que llenas manualmente, la memoria se forma automáticamente.

## Cómo funciona

Durante las conversaciones el agente recuerda:

- Preferencias y detalles que mencionas
- Contexto de tareas y proyectos actuales
- Tu estilo de comunicación

## Gestionar la memoria

**Para que el agente recuerde algo específico**, díselo en el chat:

```text
Recuerda: prefiero respuestas cortas sin introducciones.
```

**Para que el agente olvide**:

```text
Olvida lo que dije sobre el proyecto X — está cancelado.
```

## Memoria vs Conocimiento

| Memoria | Conocimiento |
| --- | --- |
| Se forma automáticamente | Lo llenas manualmente |
| Detalles personales de conversaciones | Info de referencia, roles, reglas |
| Cambia con el tiempo | Se mantiene estable |

## Prioridad en conflicto

El Conocimiento tiene prioridad sobre la memoria. Si dijiste algo en el chat pero el archivo de Conocimiento dice lo contrario — el agente sigue el Conocimiento.
