Una integración es el enlace entre el agente y un servicio que ya usas. Conecta Gmail — el agente lee y responde. Conecta Slack — publica en canales. Sin integraciones el agente trabaja a ciegas.

## Funciona desde el primer momento

Dos cosas disponibles de inmediato:

- **Búsqueda web** — encuentra información actualizada sobre cualquier tema
- **Lector de páginas** — abre cualquier URL pública y lee su contenido

## Qué puedes conectar

| Servicio | Qué hace el agente por ti |
| --- | --- |
| **Gmail** | Lee, redacta, envía, organiza |
| **Google Calendar** | Ve reuniones, crea y actualiza eventos |
| **Google Drive** | Abre archivos, crea nuevos, vigila cambios |
| **Google Docs / Sheets** | Lee y edita documentos |
| **Slack** | Lee canales y publica mensajes |
| **GitHub / GitLab** | Revisa issues, ramas, pull requests |
| **Notion / Supabase** | Trabaja con páginas y bases de datos |

## La forma más rápida — via chat

Solo dile al agente qué quieres. Él determina qué conectar y te pide que inicies sesión.

```text
Conecta mi Gmail y envíame un resumen de correos importantes cada tarde
```

La autorización ocurre en el chat — un clic y listo.

## Conectar manualmente

1. Abre **Cerebro → Integraciones**
2. Encuentra el servicio
3. Haz clic en **\+ Añadir**
4. Concede el acceso solicitado

![Cerebro → Integraciones con botones «+ Añadir»](/images/en/07-integrations-apps.png)

## Gestionar servicios conectados

Para cada integración puedes:

- **Cambiar cuenta** — vincular una cuenta diferente
- **Deshabilitar** — pausarla
- **Eliminar** — desconectar completamente

> ⚠️ Eliminar una integración rompe todas las tareas que la usan. Mejor deshabilitarla primero.
