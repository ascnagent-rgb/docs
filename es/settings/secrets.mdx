---

**Secretos** son variables de entorno para almacenamiento seguro de tokens, claves API y otras credenciales. El agente las usa al llamar a servicios externos, y nunca se muestran en texto plano.

![Configuración → Secretos y claves](/images/en/16-secrets.png)

## Cuándo necesitas secretos

Al conectar tus propias APIs o servicios que necesitan claves de autenticación. Por ejemplo:

- Una clave API para un servicio de terceros
- Un token para un Slack corporativo
- Claves de webhook

<Info>
  Los conectores estándar (Gmail, Google Calendar, Slack) se autorizan via OAuth — no necesitas secretos para ellos.
</Info>

## Cómo añadir un secreto

1. Abre **Configuración → Secretos y claves**
2. Haz clic en **\+ Añadir secreto**
3. Introduce el **nombre** (por ejemplo `API_KEY`) y el **valor**
4. Guarda

## Seguridad

- Los valores de los secretos están cifrados y no se muestran después de guardar
- Los secretos no aparecen en el historial de chat ni en los registros
- Puedes eliminar un secreto en cualquier momento
