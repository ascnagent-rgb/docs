## Принципы

- **Каждый агент работает отдельно** — данные одного агента недоступны другому
- **Пароли и ключи хранятся в зашифрованном виде** — никто, кроме вас, к ним не имеет доступа
- **Вы сами решаете, что агент может делать** — отправлять письма, удалять файлы, создавать события — каждое действие требует вашего разрешения
- **Доступ можно отозвать в любой момент** — отключите любой сервис или удалите агента полностью

## Что агент не делает без вашего разрешения

- Не отправляет письма
- Не делится вашими данными с другими пользователями
- Не использует ваши данные для обучения моделей ИИ
